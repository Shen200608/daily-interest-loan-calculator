# 使用说明

这套工具有**两个版本**，功能一模一样，挑一个用就行：

| 版本 | 怎么用 | 适合场景 |
|---|---|---|
| **网页版** | 双击 `index.html`，或访问线上网址 | 手机/电脑都能用，不用装任何东西 |
| **桌面版** | 双击 `LixiCalculator.exe`（或 `python app.py`） | 断网、想要本地软件、需要导出表格 |

## 一、我要算「本金放一天能赚多少，哪种产品更划算」

打开 **利息计算** 页（默认页）。

1. **本金**：填你打算投的钱，比如 `100000`
2. **收益率 A**：点下拉框选一个（比如「[存款] 余额宝 7 日年化」），或者直接在右边输入框填年化 `1.5`
3. **收益率 B**：再选一个（比如「[官方] 3 年期定期存款」），填 `2.75`
4. 下面立刻显示：

```
A 每日利息     ¥4.11
B 每日利息     ¥7.53
差额（每日）   +¥3.42        ← B 比 A 每天多 ¥3.42
差额（每年）   +¥1,248.30
结论：B 的收益率更高，每年多赚 ¥1,248.30
```

**小技巧**
- 想看「放 30 天能赚多少」→ 把「持有天数」改成 30，看「累计收益」表里的「期间利息」
- 想算复利 → 打开「复利（按日计息）」开关
- 银行说「按月计息按 30 天」→ 把「计息基准」从 365 切成 360

### 「持有期间与计息口径」这三个设置分别管什么

很多产品不是整年期的（7 天通知存款、90 天理财），所以要区分「每天的利息」和「这段时间总共的利息」。
界面里这个设置区就排在**「累计收益」表正上方**，因为它只作用于下面那张表。

| 设置 | 作用 | 改它会影响什么 | 不会影响什么 |
|---|---|---|---|
| **持有天数**<br>（7/30/90/365/自定义） | 这笔钱放多久 | 只改「期间累计利息」和「到期本息」 | 每日、每月、每年利息**完全不变** |
| **计息基准**<br>（日历天 365 / 360 天） | 一年按多少天折算日利率 | 每日利息、期间利息**全部会变** | — |
| **复利开关** | 利息是否滚入本金继续生息 | 只影响期间累计 | 每日、每月、每年那三个数不变 |

**举例**（本金 1 万、年化 3.65%）：

```
持有天数 7 / 30 / 90 / 365 天
  → 每日利息始终 ¥1.00，每月 ¥30.42，每年 ¥365.00   ← 不变
  → 期间累计：¥7 / ¥30 / ¥90 / ¥365                 ← 只有这个在变

计息基准 365 → 每日 ¥1.00，30 天累计 ¥30.00
计息基准 360 → 每日 ¥1.01，30 天累计 ¥30.42        ← 同样年化，360 基准多 0.42 元
```

> **什么时候用 360 天？** 银行同业业务、部分信用卡、外币业务按 360 天计息，
> 同样的「年化利率」在 360 基准下，实际到手会略多一点。国内人民币存贷款、理财产品普遍按 365。

**复利是怎么算的**：按**日**复利，日利率 = 年化 ÷ 365，终值 = 本金 ×(1 + 日利率)^天数。
所以复利结果**一定不会少于单利**，且持有越久差距越大：

```
本金 1 万、年化 3.65%：30 天  单利 ¥30.00 / 复利 ¥30.04   （差 4 分）
                        1 年  单利 ¥365.00 / 复利 ¥371.72 （差 ¥6.72）
本金 1 万、年化 24%：  30 天  单利 ¥197.26 / 复利 ¥199.15 （差 ¥1.89）
```

> 如果你看到「复利比单利还少」，那一定是算错了——工具已内置回归测试防止这一点。

打开复利后，「累计收益」表会自动多出几行：先是复利结果，再是「单利对照」行和「复利增益」行，
方便你一眼看出复利到底多赚了多少。

## 二、我要算「贷款每个月还多少，多少是利息」

打开 **贷款计算** 页。

1. **贷款本金**：比如 `1000000`
2. **年利率**：填 `4.9`（或者从下拉框选「[官方] 5 年期以上 LPR」，会自动带上加点）
3. **贷款期限**：填 `30`，单位选「年」→ 自动换算成 360 期
4. **还款方式**：选一种

四种方式的区别（同样的本金利率，总利息差很多）：

| 还款方式 | 特点 | 适合 |
|---|---|---|
| **等额本息** | 每月还的钱一样多，前期利息多本金少 | 最主流，房贷默认 |
| **等额本金** | 每月还的本金一样，月供逐月递减，总利息最少 | 收入较高、想省利息 |
| **先息后本** | 每月只还利息，到期一次性还本金 | 短期周转、经营贷 |
| **到期一次还本付息** | 期间不还，到期连本带息一起还 | 短期拆借 |

结果区会显示：

```
每期月供        ¥5,307.27
总利息          ¥910,616.58   ← 30 年一共要付这么多利息
总还款          ¥1,910,616.58
利息占比        47.7%         ← 接近一半的钱是利息
```

下面还有**逐期明细表**：

| 期数 | 月供 | 本期本金 | 本期利息 | 剩余本金 |
|---|---|---|---|---|
| 1 | 5307.27 | 1224.77 | 4083.33 | 998775.23 |
| 2 | 5307.27 | 1229.77 | 4077.50 | 997545.46 |
| … | | | | |

> 看第 1 期：月供 5307 元里，**4083 元是利息，只有 1225 元在还本金** —— 这就是「多少是利息多少是本金」。
> 越往后利息越少、本金越多，最后一期几乎全是本金。

点 **导出 CSV** 可以把整张表存成 Excel 能打开的文件。

## 三、我要算「网贷每天要还多少、每天利息多少」

打开 **网贷计算** 页。

1. **借款金额**：比如 `10000`
2. **平台利率**：从下拉框选平台（如「[网贷] 借呗（常见区间）」），会自动带出年化；也可以自己填
3. **借款天数**：比如 `30`，或者按期数算
4. **还款方式**：每日还息到期还本 / 每日等额本息

结果：

```
每日利息      ¥5.00      ← 日息万5
每日还款      ¥5.00      ← 只还息的话每天只要 5 块
总利息        ¥150.00
总还款        ¥10,150.00
```

**风险提示条**会自动判断：
- 综合年化 **超过 24%** → 橙色提醒（助贷/消费金融的综合融资成本红线）
- 综合年化 **超过 36%** → 红色警告（司法实践中常被视为高利贷口径）

> 💡 判断网贷贵不贵，看**年化**不要看「日息万几」。
> 日息万5 听起来很少，年化其实是 **18.25%**。
> 用「利率换算」页可以一键看到任何日息的真实年化。

## 四、我要把「月息1分」「日息万5」换成真实年化

打开 **利率换算** 页。

输入任意一个口径，比如「月息 1 分」，立刻得到：

```
年化利率     12.00%
月利率       1.00%
日利率       0.0329%
日息万几     万 3.29
月息几分     1.00 分
年息几分     1.20 分
月息几厘     10.00 厘
月息几毫     100.00 毫
基点         1200 BP
```

### ⚠️ 最容易踩的坑：「1 分」有两套含义

| 说法 | 含义 | 年化 |
|---|---|---|
| **月息 1 分** | 每月 1% | **12%** |
| **年息 1 分** | 每年 10% | **10%** |
| **月息 1 分 5** | 每月 1.5% | 18% |
| **月息 2 分** | 每月 2% | 24%（已到红线） |
| **月息 3 分** | 每月 3% | **36%（高利贷口径）** |
| 月息 3 厘 | 每月 0.3% | 3.6% |
| 日息万 5 | 每天 0.05% | 18.25% |

> 民间说「几分利」**默认指月息**，但有的地方指年息，签合同前一定要问清楚是哪个。
> 本工具两种都给了，对照着看。

### 分期手续费不是利率

信用卡/网贷说「月费率 0.6%」，听起来年化 7.2%，但因为你每个月都在还本金、实际占用的钱越来越少，**真实年化约 13%~13.9%**。
用页面里的「分期手续费 → 真实年化」小工具算一下就知道了。

## 五、利率大全：所有利率和它们的别名

打开 **利率大全** 页，按五类浏览：

- **官方口径**：LPR、公积金贷款、存款挂牌、Shibor、国债、政策利率…
- **民间叫法**：月息几分/几厘/几毫、日息万几、年息几分…
- **存款/理财**：余额宝 7 日年化、万份收益、业绩比较基准、储蓄国债…
- **贷款/房贷**：首套/二套房贷、经营贷、消费贷、车贷、助学贷…
- **网贷/消费金融**：各平台常见区间

顶部搜索框支持**别名和口语**：搜「万五」「1分」「7日年化」「公积金」都能找到。
每条都有 `asOf`（这个数据是哪天的）和来源链接。

点「用这个」按钮可以直接跳到利息计算页并填入该利率。

## 六、常见问题

**Q：为什么直接双击打开的网页，利率选项比线上少？**
浏览器的安全策略不允许 `file://` 页面读取同目录的 JSON 文件。此时工具会自动用内置的常用利率，并在顶部提示。
想要完整利率库：
- 用线上网址访问，或
- 在项目目录执行 `python -m http.server 8000`，然后打开 `http://localhost:8000`

**Q：结果和我银行 App 里的数字差几块钱？**
正常。银行房贷可能按「30 天/月」计息、可能按放款日实际天数首期不对齐、可能有提前还款/调整利率。本工具是**估算和横向对比**用的。

**Q：数据会上传吗？**
不会。网页版是纯前端计算，断网也能用（PWA 可离线）。桌面版完全离线。

**Q：利率数据过期了怎么办？**
`data/rates.json` 可以自己改，改完运行 `python tools/validate_rates.py data/rates.json` 检查格式。LPR 每月 20 日公布，建议关注。

**Q：算出来的年化特别高，是不是算错了？**
先看是不是选了「日息万几」这类口径。年化 36% 以上会触发红色警告——这时候不是算错，是这东西真的很贵。
