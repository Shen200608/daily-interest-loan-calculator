# 利息计算器 · Lixi Calculator

> 输入本金 + 两个收益率，立刻看出哪个更划算；贷款多少是利息、多少是本金、要还多久，一张表全列清楚；网贷每天还多少、每天利息多少，一目了然。

**双端交付**：一个网页（可直接双击打开，也可部署成 GitHub Pages 网址）+ 一个 Windows 桌面软件（Python Tkinter，无需安装第三方库）。

---

## 功能

### 1. 利息计算（首页）
- 输入**本金**，下面并排**两个收益率输入框 A / B**，自动判断哪个更高、每天/每月/每年差多少钱
- 收益率可以**下拉选**（内置 100+ 种官方口径与民间叫法），也可以**直接手填年化 %**
- 持有天数（7/30/90/365/自定义）、365/360 计息基准、复利开关——这三项排布在「累计收益」表正上方，只作用于累计收益
- 输出：每日利息、每月利息、每年利息、期间累计利息、到期本息（开复利时另附单利对照与复利增益）

### 2. 贷款计算
- 四种还款方式：**等额本息 / 等额本金 / 先息后本 / 到期一次还本付息**
- 汇总：每期月供、总利息、总还款、**利息占比可视化**（多少是利息、多少是本金）
- **逐期明细表**：期数 / 月供 / 本金 / 利息 / 剩余本金，可导出 CSV
- 「要还多久」：按月或按年输入期限，自动换算总期数

### 3. 网贷计算
- 内置主流平台利率区间（借呗、花呗、微粒贷、金条、度小满、360 借条、美团借钱、抖音放心借等）
- 输出：**每日利息、每日还款额**、总利息、总还款、按天明细
- 两种还款方式：每日还息到期还本 / 每日等额本息
- **风险提示**：综合融资成本超过 24% 橙色提醒、超过 36% 红色警告

### 4. 利率换算
- 输入任一口径，一次输出 10 种表示：年化 / 月化 / 日化 / 日息万几 / 月息几分 / 年息几分 / 月息几厘 / 年息几厘 / 月息几毫 / 基点
- 民间「分、厘、毫」对照表，并特别标注**「月息1分 = 12%/年」而「年息1分 = 10%/年」**的陷阱
- 分期手续费 → 真实年化（IRR）换算器

### 5. 利率大全
- 按官方 / 民间 / 存款理财 / 贷款房贷 / 网贷消费金融 五类浏览全部利率
- 支持别名、口语搜索（搜「万五」「1分」「7日年化」都能命中）
- 每条都带 `asOf` 更新日期、适用条件说明和来源链接

## 快速开始

### 网页版

**方式一：直接打开**
双击 `index.html` 即可使用（纯前端，数据在浏览器本地计算，不联网、不上传任何数据）。

> 直接双击（`file://` 协议）时浏览器会拦截读取 `data/rates.json`，此时页面会自动切换到内置的常用利率数据集并在顶部提示。想要完整利率库，用方式二或方式三。

**方式二：本地起一个静态服务**
```bash
# 任选其一，在项目根目录执行
python -m http.server 8000
# 然后浏览器打开 http://localhost:8000
```

**方式三：线上访问**
仓库已配置 GitHub Actions 自动部署，推送到 `main` 后自动发布到 GitHub Pages。
地址形如：`https://<你的用户名>.github.io/<仓库名>/`

### 桌面版（Windows / macOS / Linux）

```bash
cd desktop
python app.py
```

- 需要 **Python 3.9+**，只用标准库（tkinter），无需 `pip install` 任何东西
- 自检（无界面环境也能跑）：
  ```bash
  python app.py --selftest
  ```

打包成单个 exe（可选）：
```powershell
cd desktop
powershell -ExecutionPolicy Bypass -File build.ps1
```

## 精度与口径说明

| 项目 | 本工具做法 |
|---|---|
| 年基准天数 | **365 天**（可在界面切换为 360 天银行口径） |
| 金额精度 | 四舍五入到分（2 位小数） |
| 计息方式 | 默认单利；利息计算页可切换复利 |
| 分期还款 | 最后一期强制结平，保证 Σ本金 恒等于贷款本金 |
| 真实年化 | 分期手续费类用 IRR 折算（`((1+月IRR)^12-1)`），不是简单 ×12 |

> ⚠️ 银行房贷的实际计息可能按「按月计息、按 30 天/月」或「按实际天数」处理，与 365 天口径存在细微差异（通常在几元以内）。本工具结果用于估算与横向对比，**最终以金融机构合同与还款计划书为准**。

## 数据来源与更新

`data/rates.json` 中 `meta.updated` 表示整体更新时间，每条利率还有自己的 `asOf`。
官方利率会调整（尤其 LPR 每月 20 日公布），建议定期更新：

1. 修改 `data/rates.json` 里对应条目的 `value` / `min` / `max` / `asOf` / `source`
2. 更新 `meta.updated`
3. 运行 `python tools/validate_rates.py data/rates.json` 确认格式正确
4. 提交

详见 [docs/利率大全.md](docs/利率大全.md)。
